## Compare before you buy. Without leaving Steam.

Stan brings a focused price comparison into Steam itself. When a reliable
comparison is available, it appears next to the price you are already viewing.
When it cannot be proven, Stan stays quiet.

## Private by design. Open to inspection.

- **No account.** Nothing you do is tied to a name or a profile.
- **Only Steam pages.** No access to your browsing history, cookies or other sites.
- **One destination.** The extension talks to a single Stan API origin, without credentials.
- **No remote code.** Everything that runs ships inside the store-reviewed package.
- **Verifiable.** The browser code of every store package is public, and one
  command checks that the store package matches it.
